# Smart-Water-Reminder
基于51单片机的智能饮水提醒系统
## 项目介绍
本项目基于51单片机设计并实现了一套简易饮水提醒系统。
系统通过独立按键实现用户饮水次数记录，并利用定时器完成时间控制，通过蜂鸣器实现声音提醒功能，帮助用户养成规律饮水习惯。
项目从基础单片机控制出发，实现了输入检测、数据记录、定时控制以及输出提醒等嵌入式系统基本功能。
后续计划进一步加入传感器、显示模块以及无线通信功能，实现更加智能化的人机交互。
## 功能特点
- 独立按键检测，实现用户操作输入
- 饮水次数累计记录
- 达到设定次数后触发蜂鸣器提醒
- 基于定时器实现周期性提醒
- 模块化程序设计，便于功能扩展
## 硬件平台
- STC89C52RC 51单片机
- 51单片机开发板
- 独立按键模块
- 蜂鸣器模块
